# Почему точка opt «вне» розовой ОДР на графике

## Краткий ответ (для защиты)

Оптимум **всегда** лежит **внутри** математической ОДР: он выбирается только из точек, прошедших проверку всех 11 неравенств. Если на экране **opt** кажется снаружи розовой зоны — это **ошибка отрисовки** (неправильный порядок вершин при заливке), а не ошибка расчёта.

## Подробно

1. `FindOptimum` перебирает пересечения границ и углы `[n_min, n_max] × [s_min, s_max]`.
2. `ConsiderPoint` добавляет точку только при `IsFeasible = True`.
3. Оптимум — вершина с максимальным `x1 + x2`.

`GraphPlotUnit` строит полигон по массиву вершин. Старая сортировка по углу от **первой вершины в экранных пикселях** давала самопересечение контура → «кривая» заливка.

**Исправление:** сортировка индексов вершин по `ArcTan2(x2 - cy, x1 - cx)` в координатах **x1, x2**, затем проекция на экран.

Перекомпилируйте проект после `git pull`.

## Примечание

В memo список вершин может содержать **дубликаты** (угол станка = пересечение L8×L9 и т.п.) — на расчёт это не влияет.
