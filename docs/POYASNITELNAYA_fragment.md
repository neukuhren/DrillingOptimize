# Фрагмент пояснительной записки (черновик)

## Постановка задачи

По заданным технологическим и станочным ограничениям найти режимы сверления — частоту вращения **n** и подачу **s**, при которых достигается максимум критерия производительности в логарифмических координатах:

\[
L_a = x_1 + x_2 \to \max,\quad x_1 = \ln n,\quad x_2 = \ln(100s).
\]

## Исходные зависимости

Скорость резания при сверлении (справочник технолога, т. 2, с. 382):

\[
v = \frac{C_v D^q}{T^m s^y} K_v.
\]

Связь с частотой вращения:

\[
v = \frac{\pi D n}{1000}.
\]

После преобразований получаем ограничение вида \(n s^y \le C\), которое после логарифмирования входит в систему линейных неравенств (аналог п. 3.2–3.35 методички для точения).

## Метод решения

1. Записать ограничения в виде \(a_1 x_1 + a_2 x_2 \le b\) (или \(\ge\)).
2. Для каждой пары границ построить систему двух уравнений и решить **методом определителей** (процедура `Determinant`).
3. Отобрать точки, удовлетворяющие **всем** неравенствам (область допустимых решений).
4. Вычислить \(L_a = x_1 + x_2\); выбрать максимум.
5. Обратная подстановка: \(n = e^{x_1}\), \(s = e^{x_2}/100\), \(V = \pi D n / 1000\).

## Программная реализация

Язык **Object Pascal**, среда **Lazarus**. Модули расчёта отделены от формы ввода и графика. Параметры сохраняются в INI для повторных расчётов.

## Графическая интерпретация

На плоскости \((x_2, x_1)\) строятся прямые ограничений; заштрихованная область — ОДР; отмечена точка оптимума.

## Сравнение результатов

В программе выводятся оптимальные **n, s, V** и справочный ориентир по формуле скорости для сопоставления «расчётное / оптимальное» (по требованию курсовой).
