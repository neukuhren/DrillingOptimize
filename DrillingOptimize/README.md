# Оптимизация режимов сверления (Lazarus / Free Pascal)

Учебный проект: линеаризация ограничений, поиск оптимума **La = x1 + x2 → max** перебором пар прямых (метод определителей), график ОДР, расчёт **n**, **s**, **V**.

## Среда

- **Lazarus 4.8**, **FPC 3.2.2**, Windows x64 (у вас на скриншоте).
- Открыть `DrillingOptimize.lpi` → **Run**.

## Структура

| Файл | Назначение |
|------|------------|
| `CuttingModel.pas` | Ограничения, `FindOptimum`, декодирование режимов |
| `DeterminantMethod.pas` | Процедура `Determinant` по методичке |
| `GraphPlotUnit.pas` | Отрисовка прямых и ОДР |
| `MainFormUnit.pas` | Форма, INI, результаты |

## Подстановки

- \(x_1 = \ln n\)
- \(x_2 = \ln(100s)\)
- Сверление, формула скорости (справочник, с. 382):  
  \(v = C_v D^q T^{-m} s^{-y} K_v\), связь с \(n\) через \(v = \pi D n / 1000\).

Первое ограничение пересчитывается из **D, T, Cv, q, m, y, Kv** (поля формы). Остальные коэффициенты — как в примере методички для точения, **все редактируемые** на форме.

## INI

Кнопки **Сохранить / Загрузить** → `drilling_params.ini` рядом с exe.

## Проверка

1. **D = 10** и **D = 12**, материал СТ20: подставьте **Cv, y, m** из таблиц к формуле на с. 382.
2. Сравните **n, s, V** со справочным блоком в memo и с вашим ориентиром (~0.27 мм/об, 325 об/мин при D≈11).
3. При расхождении с методичкой — скорректируйте **b3, жёсткость, прочность** на форме (или пришлите числа из примера курсовой — подстроим defaults).

## Сборка exe

Project → Build. Исполняемый файл **`DrillingOptimize.exe`** создаётся в **корне папки проекта** (в `.lpi` задано `-FE$(ProjPath)`). Если запуск из IDE пишет «файл не найден» — сделайте **Project → Build** и проверьте, что в каталоге проекта есть `DrillingOptimize.exe` (не только в `lib\...`).

**Важно:** открывайте **`DrillingOptimize.lpi`** в каталоге, где лежат `.pas` и `.lfm` (например **`D:\DrillingOptimize`**; без лишней вложенности `DrillingOptimize\DrillingOptimize`).

После открытия проекта: двойной щелчок по **MainFormUnit** в Project Inspector → вкладка **Form** (дизайнер). Поля параметров создаются в коде в `FormCreate`, в `.lfm` только кнопки, memo и график.

## Исправления совместимости (Lazarus 2.x / 4.x)

- `GraphPlotUnit`: unit **Math** для `ArcTan2`.
- Не называйте локальную переменную **`Top`** в форме (конфликт с `Controls.Top`).
- Прокрутка: **`ScrollBox.VertScrollBar.Range`**, не `VertScrollRange`.
