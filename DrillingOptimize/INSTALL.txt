Установка в C:\DrillingOptimize
================================

1. Распакуйте ВСЕ файлы этого архива В ПАПКУ C:\DrillingOptimize
   (в каталоге должен лежать файл DrillingOptimize.lpr рядом с .lpi).

2. Обязательные файлы в одной папке:
   DrillingOptimize.lpr
   DrillingOptimize.lpi
   MainFormUnit.pas / MainFormUnit.lfm
   CuttingModel.pas, GraphPlotUnit.pas, DeterminantMethod.pas

3. Lazarus 4.8: Проект -> Открыть проект -> DrillingOptimize.lpi
   Проект -> Собрать -> F9

Содержимое DrillingOptimize.lpr (главная программа):
   RequireDerivedFormResource := True;
   Application.Initialize;
   Application.CreateForm(TMainForm, MainForm);
   Application.Run;

Архив: DrillingOptimize-2026-11-11.zip (корень без лишней вложенности).
