# Сборка в Lazarus (если ошибка «нет главного файла исходного кода»)

## Правильный порядок

1. Запустите **Lazarus**.
2. **Проект → Открыть проект** (не только «Открыть файл»): выберите  
   `C:\DrillingOptimize\DrillingOptimize.lpi`
3. В **Инспекторе проектов** (слева) должны быть 5 модулей, первым — **`DrillingOptimize.lpr`**.
4. **Проект → Скомпилировать** (или **Собрать**).
5. **Запуск → Выполнить** (**F9**).

Горячие клавиши: в Lazarus сборка — часто **Ctrl+Shift+F9** или меню **Проект**, а не обязательно **Ctrl+F9**.

---

## Если снова «Проект не имеет главного файла исходного кода»

### Способ 1 (надёжный): открыть программу `.lpr`

1. **Файл → Открыть**
2. Выберите **`DrillingOptimize.lpr`** (не `.lpi`).
3. Lazarus спросит, добавить в проект — согласитесь или сохраните проект заново.
4. **Проект → Сохранить проект как…** → тот же каталог → `DrillingOptimize.lpi`.

### Способ 2: новый проект из шаблона

1. **Проект → Новый проект → Application**
2. Сохраните в `C:\DrillingOptimize` (временно другое имя).
3. Замените сгенерированные `.pas` / `.lfm` / `.lpr` нашими файлами из репозитория.
4. **Проект → Добавить в проект** → добавьте `CuttingModel.pas`, `GraphPlotUnit.pas`, `DeterminantMethod.pas`.
5. В `.lpr` в `uses` оставьте `MainFormUnit` и `Interfaces, Forms`.

## Где должен быть `.exe`

После **успешной** сборки:

- **`C:\DrillingOptimize\DrillingOptimize.exe`** (в `.lpi` задано `-FE$(ProjPath)`).
- Промежуточные файлы — в **`C:\DrillingOptimize\lib\x86_64-win64\`** (появится после первой сборки).

Если **`lib\...` пусто** и **exe нет** — сборка **не выполнялась** (ошибка проекта или компиляции). Смотрите окно **Сообщения** внизу IDE.

---

## Каталог вывода модулей в настройках

**Проект → Параметры проекта → Параметры компилятора → Пути**:

- **Каталог вывода модулей:** `lib\$(TargetCPU)-$(TargetOS)`
- **Имя исполняемого файла:** `DrillingOptimize`
- **Доп. параметры** (вкладка «Прочее» / Custom options): `-FE$(ProjPath)`

Папки **`docs`** и **`scripts`** к компиляции не относятся — в них нет `.ppu` / `.exe`.

---

## Ошибка `SynchronizeFormWakeups` (Lazarus 2.0.x)

В старых версиях LCL нет свойства `Application.SynchronizeFormWakeups`. В актуальном `DrillingOptimize.lpr` эта строка **удалена**. Обновите файл из репозитория или удалите строку 16 вручную.

## Распаковка

Все файлы проекта (**`.lpr`, `.lpi`, `.pas`, `.lfm`**) должны лежать **в одной папке** `C:\DrillingOptimize`, без лишнего уровня `DrillingOptimize\DrillingOptimize\`.
